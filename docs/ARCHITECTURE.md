# Architecture — v0.6.0

React/Vite frontend in src/. Models are abstract, dimensionless and uncalibrated. The descriptive substrate comparison does not select a calibrated kinetic model.

## Work/Sites deployment

The Worker is generated by scripts/build.mjs after the frontend build. It embeds frontend assets and the public reading bundle. worker/handler.mjs uses prepared single-statement D1 queries; immutable migrations live in drizzle/. The existing Sites project retains its D1 records across publications. /api/info and /api/openapi.json expose JSON, /readme.md full documentation and source, /api/project a source index, /mcp and /api/mcp model tools. Public proposals are untrusted text; they never modify code automatically.

## Optional Express deployment

server.ts serves the same API concepts over Node/Express. SQLITE_PATH chooses a database file. Cloud Run local filesystem alone is ephemeral; SQLITE_DURABLE_VOLUME=true must only be set after a persistent volume and path are genuinely configured. Cloud writes return 503 otherwise, preserving browser input. Local SQLite restart tests prove persistence only for the reused local file, not for Cloud Run. Metadata headers from arbitrary clients are not trusted for rate limiting.

## Models and verification

src/utils/kinetics.ts implements browser analytics and adaptive RK4. Output grid is 0.05, internal maximum step 0.005; these are distinct. Product-slope roots and rate crossings are refined by bisection and reintegration. Sensitivities use the documented observation times and direct SVD. Temperature is metadata. Public dist-core/*.mjs implements the independent MCP model functions. Python provides fixed-step comparison models. Tests compare equations, analytic limits, conservation, convergence, HTTP behavior and storage. They do not validate chemistry.

## Statistics and exports

The browser loss profile reoptimizes other rates, with a heuristic normalized score and reference 3.84. It does not establish confidence bounds. PEtab tables use an assumed noise value and are an incomplete draft, not a validated importable project. CSV data stays in the browser. All UI/README/model-reference claims must agree with these limits.
